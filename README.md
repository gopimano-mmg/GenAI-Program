# Student Grade System

This project is a simple Python program that converts a student's mark into a grade.

The user enters a mark between 0 and 100, and the program displays the correct grade.

## Grade Rules

- 90 to 100 = Grade A
- 80 to 89 = Grade B
- 70 to 79 = Grade C
- 60 to 69 = Grade D
- Below 60 = Grade E

## How To Run

Open the terminal in this folder and run:

```bash
python3 grade_system.py
